Fase 1 — Setup y Base (1-2 días)
 Inicializar proyecto Next.js 15 con pnpm
 Configurar Tailwind + shadcn/ui
 Crear cuenta en Clerk, configurar auth (Google + email/password)
 Crear proyecto en Supabase, correr migración Drizzle
 Configurar RLS y storage bucket
 Variables de entorno en Vercel
 Folder structure + tipos base
Fase 2 — Storefront público (3-4 días)
 Layout: header con navegación + búsqueda, footer
 Home: hero, categorías, productos destacados, sección confianza
 Catálogo: grid con filtros (categoría, precio, tamaño), paginación
 Detalle producto: galería, info, selector de variantes, agregar al carrito
 Página de categorías
Fase 3 — Carrito + Checkout (2-3 días)
 Carrito: slide-over, actualizar cantidades, eliminar, subtotal
 Checkout: datos de envío, método de entrega (flexible), resumen
 Integración MercadoPago (crear preferencia, webhooks)
 Página de confirmación de pedido
Fase 4 — Mi Cuenta + Auth (1-2 días)
 Páginas de login/register con Clerk
 Perfil: editar datos, direcciones guardadas
 Historial de pedidos
Fase 5 — Panel Admin (4-5 días)
 Dashboard: KPIs (ventas, pedidos pendientes, productos top)
 CRUD productos: crear/editar con galería, variantes, stock
 Gestión de órdenes: lista + detalle, cambiar estados
 CRUD categorías
 Gestión de cupones
 Configuración general
Fase 6 — Polish + Deploy (1-2 días)
 Emails transaccionales (confirmación de pedido)
 SEO: metadata, sitemap, structured data
 Optimización de imágenes y performance
 Deploy en Vercel + dominio
Inversión estimada: ~15-20 horas de desarrollo
